HTML Tables

Introduction

HTML tables are used to organize data into rows and columns. They are useful for displaying structured information such as schedules, grades, and lists.

Basic Table Structure

<table>
  <tr>
    <th>Header 1</th>
    <th>Header 2</th>
  </tr>
  <tr>
    <td>Data 1</td>
    <td>Data 2</td>
  </tr>
</table>

Example Table

Name Course Year
Ana BSIT 2nd Year
John BSCS 1st Year

Table Tags Explained

<table> – Creates a table

<tr> – Table row

<th> – Table header

<td> – Table data cell

Importance of Tables

  • Organizes data clearly
  • Makes information easier to read
  • Useful for reports and schedules
  • Improves data presentation in websites

Conclusion

HTML tables are an important part of web design because they help present data in a structured and readable format. Mastering tables is essential for creating organized web pages.
