CSS (Cascading Style Sheets)

Introduction

CSS (Cascading Style Sheets) is used to style and design HTML webpages. It controls the layout, colors, fonts, spacing, and overall appearance of a website. Without CSS, websites would look plain and unformatted.

Ways to Apply CSS

  • Inline CSS – Applied inside HTML elements
  • Internal CSS – Written inside <style> tag
  • External CSS – Separate .css file linked to HTML

Example of Inline CSS

<p style="color: red;">This is a red text</p>

Example of Internal CSS

<style> p { color: blue; } </style>

CSS Properties

color – changes text color

background-color – changes background

font-size – changes text size

margin – space outside element

padding – space inside element

Why CSS is Important

  • Makes websites visually appealing
  • Improves user experience
  • Separates design from content
  • Allows responsive design for different devices

Example Styling Concept

body { background-color: lightblue; font-family: Arial; } h1 { color: darkblue; text-align: center; }

Conclusion

CSS is an essential part of web development. It allows developers to design attractive and user-friendly websites by controlling the appearance of HTML elements.
