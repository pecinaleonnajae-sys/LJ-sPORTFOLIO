HTML Structure

Introduction

HTML (HyperText Markup Language) is the standard language used to create webpages. It provides the basic structure of a website by organizing content such as text, images, and links. Understanding HTML structure is important because it serves as the foundation of all web development.

Basic HTML Structure

<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    Content goes here
  </body>
</html>

Parts of HTML Structure

  • <!DOCTYPE html> – Declares the document type
  • <html> – Root element of the page
  • <head> – Contains metadata
  • <title> – Page title in browser tab
  • <body> – Visible content

Semantic HTML Structure

  • <header> – Top section
  • <nav> – Navigation menu
  • <main> – Main content
  • <section> – Grouped content
  • <article> – Independent content
  • <footer> – Bottom section

Example of Semantic Structure

<header>
  <h1>My Website</h1>
</header>

<nav>
  <a href="#">Home</a>
  <a href="#">About</a>
</nav>

<main>
  <section>
    <h2>Welcome</h2>
    <p>This is my webpage.</p>
  </section>
</main>

<footer>
  <p>© 2026 My Website</p>
</footer>

Importance of HTML Structure

  • Organizes content clearly
  • Improves user experience
  • Easier to maintain
  • Better SEO
  • Improves accessibility

Conclusion

HTML structure is the backbone of every website. By understanding its elements, you can create organized and effective webpages. Mastering this is the first step in web development.
